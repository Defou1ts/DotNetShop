# Развертывание проекта SimpleShop

## Предварительные условия

- Установлен .NET 7 SDK.
- Настроен доступ к базе данных MySQL либо используемый в проекте connection string в `appsettings.json`.

## Локальный запуск в режиме разработки

1. Откройте решение в IDE (Visual Studio / Rider / VS Code) или командную строку в папке проекта.
2. При необходимости отредактируйте параметры подключения к БД в файле `appsettings.json`.
3. Выполните команду:
   ```bash
   dotnet restore
   dotnet run
   ```
4. Откройте браузер и перейдите по адресу `https://localhost:5001` или `http://localhost:5000` (в зависимости от настроек).

## Публикация для развертывания

1. Выполните в корне проекта:
   ```bash
   dotnet publish -c Release -o publish
   ```
2. В результате будет создана папка `publish` с готовыми для запуска файлами.
3. Скопируйте содержимое папки `publish` на целевой сервер.

## Запуск на сервере

1. Убедитесь, что на сервере установлен .NET Runtime соответствующей версии.
2. Настройте переменную среды `ASPNETCORE_ENVIRONMENT` (например, `Production`).
3. Запустите приложение:
   ```bash
   dotnet SimpleShop.dll
   ```
4. При необходимости настройте обратный прокси (Nginx / IIS / Apache) на перенаправление HTTP(S)-запросов к приложению.
