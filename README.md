# SimpleShop

Учебный интернет-магазин на **ASP.NET Core MVC (.NET 7)** с авторизацией, корзиной, оформлением заказа и интеграцией с базой данных MySQL и SMTP‑почтой.

Проект демонстрирует полный цикл работы простого магазина:

- витрина с не менее чем четырьмя разделами и десятью+ карточками товара;
- детальная страница товара с изображением и возможностью добавления любого количества в корзину (с учётом остатка на складе);
- корзина с пересчётом сумм и проверкой ограничений по количеству;
- оформление заказа с подсчётом общей суммы и отправкой письма пользователю;
- автоматическое уменьшение остатка на складе;
- поиск товаров по названию и описанию;
- авторизация пользователей на базе ASP.NET Identity.

## Технологии и архитектура

- **Платформа**: .NET 7, ASP.NET Core MVC.
- **Язык**: C#.
- **База данных**: MySQL (через `MySql.EntityFrameworkCore`).
- **ORM**: Entity Framework Core.
- **Аутентификация**: ASP.NET Core Identity (`IdentityUser`, `IdentityDbContext`).
- **UI**:
  - Razor Views, Layout;
  - Bootstrap 5 (из `wwwroot/lib/bootstrap`) для адаптивного интерфейса;
  - простые улучшения стилей в `wwwroot/css/site.css`.
- **Кэширование**: `IMemoryCache` для списка категорий.
- **Email‑уведомления**: `SmtpClient` и настройки SMTP из `appsettings.json`.

Логика разбита на:

- **Controllers** — веб‑слой (маршрутизация, обработка запросов, подготовка моделей для представлений).
- **Models** — доменные сущности (Product, Category, CartItem, Order, OrderItem) и ViewModel’и.
- **Data** — `ApplicationDbContext` и `DbInitializer` для конфигурации EF Core и начального наполнения БД.
- **Services** — сервисы отправки почты и настройки (`IOrderNotificationService`, `EmailOrderNotificationService`, `EmailSettings`).
- **Views** — Razor‑представления для MVC‑контроллеров.

## Структура проекта

Основные директории:

- `Controllers`
  - `HomeController` — главная страница и встроенное пользовательское руководство.
  - `ProductsController` — витрина, фильтрация по разделам, поиск и страница деталей товара.
  - `CartController` — корзина, изменение количества, оформление заказа, страница подтверждения.
  - `AccountController` — регистрация, вход и выход (обёртка над Identity).
- `Data`
  - `ApplicationDbContext` — контекст EF Core c сущностями магазина и схемами Identity.
  - `DbInitializer` — начальное заполнение БД категориями и товарами.
- `Models`
  - `Category` — раздел каталога.
  - `Product` — товар (название, описания, цена, остаток, привязка к категории и ссылке на изображение).
  - `CartItem` — позиция в корзине для конкретного пользователя.
  - `Order` — оформленный заказ (контакты пользователя, состав и итоговая сумма).
  - `OrderItem` — отдельная строка заказа.
  - `OrderViewModel` — данные, вводимые пользователем на шаге оформления (форма checkout).
  - `CatalogViewModel` — модель для витрины: список категорий, продуктов, выбранный раздел, поисковая строка.
- `Services`
  - `EmailSettings` — конфигурация SMTP (сервер, порт, логин, пароль, From‑адрес).
  - `IOrderNotificationService` — абстракция сервиса уведомлений о заказе.
  - `EmailOrderNotificationService` — реализация на основе SMTP (`SmtpClient`).
- `Views`
  - `Home/Index` — главная страница с описанием возможностей.
  - `Home/Manual` — встроенное руководство пользователя.
  - `Products/Category` — витрина с фильтрацией и поиском.
  - `Products/Details` — карточка товара.
  - `Cart/Index` — корзина.
  - `Cart/Checkout` — форма оформления заказа.
  - `Cart/Confirmation` — страница подтверждения заказа.
  - `Account/Login`, `Account/Register` — страницы аутентификации.
- `wwwroot`
  - `css/site.css` — дополнительные стили (герой‑блок, карточки товаров, боковое меню разделов).
  - `images/product-placeholder.svg` — плейсхолдер для товаров без собственной картинки.
  - `lib` — Bootstrap, jQuery, jquery‑validation.

## Функциональные возможности

### Витрина и разделы

- Не менее **4‑х разделов** (категорий) — «Electronics», «Books», «Home & Kitchen», «Fitness», «Gaming».
- Блок «Разделы» в левой части страницы витрины:
  - ссылка «Все товары» сбрасывает фильтры;
  - отдельные ссылки для каждой категории.
- В основной области — карточки товаров с:
  - названием и категорией;
  - кратким описанием;
  - ценой;
  - информацией о наличии на складе (Stock);
  - кнопкой «В корзину» с выбором количества;
  - ссылкой «Подробнее».

Всего сидером создаётся **10+ товаров**; если БД уже существовала, `DbInitializer` добавит/обновит их при первом запуске.

### Карточка товара

На странице `Products/Details` показываются:

- наименование товара;
- изображение (URL из БД или дефолтная картинка);
- краткое и полное описание;
- актуальная цена;
- остаток на складе;
- форма для добавления в корзину с указанием количества:
  - минимум 1;
  - максимум — остаток на складе;
  - при нулевом остатке поля и кнопки блокируются.

### Корзина

В разделе `Cart/Index` пользователь видит:

- список выбранных товаров с:
  - названием;
  - ценой за единицу;
  - полем для изменения количества;
  - суммой по строке;
- общую сумму заказа;
- кнопки:
  - «Обновить» количество для конкретной позиции;
  - «Удалить» позицию;
  - «Оформить заказ».

Ограничения и проверки:

- количество принудительно ограничивается диапазоном от 1 до 100;
- количество не может превышать остаток товара:
  - при попытке ввести больше — количество автоматически уменьшается до остатка;
  - пользователю показывается предупреждение;
- если товар становится недоступен (Stock <= 0 или удалён), позиция удаляется из корзины с сообщением.

### Оформление заказа

Раздел `Cart/Checkout` содержит форму с полями:

- ФИО;
- Email;
- Телефон;
- Адрес доставки;
- Способ доставки (курьер, самовывоз, почта);
- Способ оплаты (карта / наличные курьеру);
- Чекбокс подписки на новости;
- Произвольный комментарий.

Рядом отображается сводка корзины:

- список товаров;
- количество и цена по каждой позиции;
- итоговая сумма.

При отправке формы:

1. Выполняется валидация введённых данных (аннотации в `OrderViewModel`).
2. Проверяется, что корзина не пуста.
3. Проверяется актуальный остаток товаров в БД (защита от гонок и устаревших данных).
4. При успешной проверке:
   - создаётся сущность `Order` с привязкой к текущему пользователю;
   - создаются `OrderItem` для каждой позиции корзины;
   - из `Product.Stock` вычитается заказанное количество;
   - считается итоговая сумма заказа (`TotalAmount`);
   - корзина очищается.
5. Пользователь перенаправляется на страницу подтверждения `Cart/Confirmation`.

### Подтверждение заказа и email‑уведомление

- На странице `Cart/Confirmation` пользователь видит:
  - номер заказа;
  - список товаров с количеством и ценой;
  - итоговую сумму;
  - введённые контактные данные, адрес и способы доставки/оплаты;
  - (при наличии) комментарий к заказу.
- Параллельно вызывается `EmailOrderNotificationService`, который:
  - строит текст письма со сводкой заказа;
  - читает настройки SMTP из секции `Email` в `appsettings*.json`;
  - отправляет письмо на указанный при оформлении адрес (или на `RecipientOverride`, если задан).

Если SMTP не настроен (пустой `SmtpHost`), сервис не падает, а пишет подробную информацию в лог.

### Поиск товаров

Поиск реализован двумя способами:

- глобальная строка поиска в шапке (`_Layout`) — отправляет запрос в `Products/Search`;
- форма поиска в боковом меню витрины.

Искомая строка ищется в:

- названии товара (`Name`);
- кратком описании (`ShortDescription`);
- полном описании (`Description`).

Результат поиска отображается тем же представлением `Products/Category`, где отфильтрованы товары по строке поиска и (опционально) по категории.

## Подготовка окружения

Необходимые компоненты:

- **.NET 7 SDK** (для разработки и локального запуска).
- **MySQL сервер** (локальный или сетевой).
- При желании **SMTP‑учётная запись**, например Gmail, для отправки подтверждений заказов.

Проверьте установку .NET:

```bash
dotnet --version
```

## Настройка базы данных MySQL

1. Создайте базу данных, например:

```sql
CREATE DATABASE simple_shop CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

2. Задайте строку подключения в `appsettings.json`:

```json
"ConnectionStrings": {
  "DefaultConnection": "server=localhost;database=simple_shop;user=root;password=root"
}
```

3. При первом запуске приложение:
   - вызовет `EnsureCreated()` для создания схемы;
   - выполнит инициализацию через `DbInitializer.Initialize`, заполнив категории и товары.

Если вы уже запускали приложение до изменений схемы, возможно, понадобится:

- вручную обновить структуру таблиц по указанным SQL‑скриптам (см. инструкцию, которую вы использовали для добавления `ImageUrl`, `ShortDescription`, `Orders`, `OrderItems`);
- либо пересоздать базу данных (для учебных целей это допустимо).

## Настройка SMTP (отправка email)

Настройки берутся из секции `Email`:

```json
"Email": {
  "Sender": "noreply@simpleshop.local",
  "SenderDisplayName": "SimpleShop",
  "RecipientOverride": "",
  "SmtpHost": "smtp.gmail.com",
  "SmtpPort": 587,
  "UseSsl": true,
  "Username": "your_email@gmail.com",
  "Password": "app_password"
}
```

Рекомендации:

- Для Gmail используйте **пароль приложения**, а не основной пароль аккаунта.
- В `appsettings.Development.json` можно задать отдельные значения для разработки.
- Поле `RecipientOverride`:
  - пустая строка — письма уходят на email, указанный пользователем в форме;
  - если задать адрес, все письма будут пересылаться только туда (удобно для тестирования).

## Локальный запуск

1. Откройте проект в IDE или терминале в корне репозитория.
2. При необходимости отредактируйте строку подключения к MySQL и секцию `Email` в `appsettings*.json`.
3. Восстановите зависимости и запустите приложение:

```bash
dotnet restore
dotnet run
```

4. Откройте браузер:
   - `https://localhost:5001` или
   - `http://localhost:5000`
     (конкретный адрес зависит от настроек Kestrel/launchSettings).

При первом запуске будут созданы таблицы БД и заполнены стартовые данные.

## Публикация и развёртывание

### Публикация

В корне проекта:

```bash
dotnet publish -c Release -o publish
```

В результате будет создана папка `publish` с:

- `SimpleShop.dll` (или исполняемым файлом для целевой ОС, если используется self-contained публикация);
- статическими файлами (`wwwroot`);
- конфигами.

### Развёртывание на сервере

1. Скопируйте содержимое папки `publish` на сервер.
2. Убедитесь, что на сервере установлен подходящий **.NET Runtime**.
3. Настройте переменную окружения:

```bash
export ASPNETCORE_ENVIRONMENT=Production
```

4. Запустите приложение:

```bash
dotnet SimpleShop.dll
```

5. (Опционально) настройте обратный прокси (Nginx / Apache / IIS) для:
   - приёма HTTP(S)‑запросов;
   - проброса их на порт, где слушает Kestrel.

## Руководство пользователя

### Назначение

SimpleShop — учебный интернет-магазин, позволяющий:

- просматривать каталог товаров по разделам;
- искать товары по названию и описанию;
- добавлять товары в корзину;
- оформлять заказы с указанием контактных данных и адреса;
- получать email‑подтверждения.

Встроенную версию руководства можно открыть из меню **«Руководство»** в шапке сайта.

### Основные разделы сайта

1. **Главная страница**
   - Кратко описывает возможности магазина.
   - Содержит крупные кнопки для перехода к витрине и корзине.
2. **Витрина**
   - Показывает список товаров с фильтрацией по разделам.
   - Отсюда можно:
     - открыть детальную страницу товара;
     - добавить товар в корзину с указанным количеством;
     - воспользоваться поиском по товарам.
3. **Корзина**
   - Отображает выбранные товары, их количество, цену и общую сумму.
   - Позволяет:
     - изменить количество товара;
     - удалить позицию;
     - перейти к оформлению заказа.
4. **Оформление заказа**
   - Форма для ввода ФИО, email, телефона, адреса, способов доставки и оплаты, комментария.
   - Справа отображается сводка корзины и итоговая сумма.
5. **Подтверждение заказа**
   - После успешного оформления показывает:
     - номер заказа;
     - состав и сумму;
     - контактные данные и адрес.
6. **Авторизация**
   - **Регистрация** — создание новой учётной записи по email и паролю.
   - **Вход** — аутентификация ранее зарегистрированного пользователя.

### Типичный сценарий работы

1. Откройте сайт и при необходимости выполните регистрацию/вход.
2. Перейдите в раздел «Витрина» и выберите нужные товары.
3. Добавьте товары в корзину, указав желаемое количество.
4. Откройте раздел «Корзина» и проверьте состав заказа.
5. При необходимости скорректируйте количества или удалите лишние позиции.
6. Нажмите кнопку «Оформить заказ» и заполните форму.
7. После успешной отправки формы откроется страница с подробной сводкой заказа; на ваш email придёт письмо с аналогичной информацией.

### Поиск и фильтрация

- Используйте поле поиска:
  - в шапке сайта (глобальный поиск);
  - в левой части витрины (поиск по разделу или по всем товарам).
- Вводите:
  - полное или частичное название товара;
  - ключевые слова из описания.
- Чтобы сбросить фильтры и увидеть все товары, нажмите «Все товары» в блоке разделов.

## Соответствие учебным требованиям

1. **Страницы:**
   - главная — `Home/Index`;
   - корзина — `Cart/Index`;
   - не менее 4 разделов — категории в витрине (`Electronics`, `Books`, `Home & Kitchen`, `Fitness`, `Gaming`);
   - не менее 10 карточек товара — задаются в `DbInitializer`.
2. **Страница карточки товара:**
   - содержит наименование, изображение, краткое и полное описание;
   - форма позволяет добавить любое количество (в разумных пределах) в корзину.
3. **Переходы и заказ:**
   - реализованы переходы между страницами через меню и ссылки;
   - подсчёт суммы заказа в корзине и при оформлении;
   - отправка заказа с переходом на страницу подтверждения и рассылкой по email.
4. **Подключение базы данных:**
   - используется MySQL через Entity Framework Core;
   - структура задаётся через `ApplicationDbContext`, а наполнение — через `DbInitializer`.
5. **Документация:**
   - **XML‑документация кода** — включено `GenerateDocumentationFile`, расставлены `///`‑комментарии над ключевыми классами и методами;
   - **Пользовательская** — данный `README.md` и встроенная страница `Home/Manual`.
6. **Сообщение пользователю при отправке заказа:**
   - страница `Cart/Confirmation` показывает, _сколько и чего_ заказано, с итоговой суммой;
   - `EmailOrderNotificationService` отправляет аналогичную информацию по email.
7. **Уменьшение остатка и ограничения:**
   - после оформления заказа `Product.Stock` уменьшается на заказанное количество;
   - при попытке заказать больше остатка количество принудительно ограничивается, пользователь получает предупреждение.
8. **Поиск товара:**
   - поиск по наименованию и описанию реализован в `ProductsController.Category` и `Search`.
9. **Сохранение текущего функционала:**
   - существующие страницы (главная, витрина, корзина, оформление, авторизация) продолжают работать;
   - новые функции (разделы, поиск, email, подтверждение, ручное руководство) аккуратно интегрированы в текущую архитектуру.

## Программная документация (XML)

- В файле проекта `SimpleShop.csproj` включена генерация XML‑документации:

```xml
<GenerateDocumentationFile>true</GenerateDocumentationFile>
```

- Над основными контроллерами, моделями и сервисами добавлены `/// <summary>...</summary>` и другие XML‑комментарии, которые:
  - помогают ориентироваться в коде;
  - могут использоваться внешними инструментами (IntelliSense, генераторы docs).

XML‑файл документации создаётся при сборке рядом с `SimpleShop.dll` и может быть использован для дальнейшей автоматической генерации справочных материалов.
